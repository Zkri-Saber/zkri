Google NotebookLM has no public API for personal accounts, so this app prepares everything for a quick hand-off instead of calling it directly.
  1. Tick the articles you want in the sidebar, then download the pack below (one Markdown file per article).
  2. Open NotebookLM → New notebook → Add sources → Upload and pick the files.
  3. Pick a task here, copy the NotebookLM prompt, and paste it in the notebook chat. Use Studio for Audio Overview, Briefing doc, or Study guide.
  4. Paste NotebookLM's answer back into the article text to keep a polished version here.
Get a free key at Google AI Studio. The key stays in this browser's local storage and is sent only to Google's API. On a public GitHub Pages site, never hard-code a key in the page; in Google AI Studio / Cloud Console restrict your key to your site's HTTP referrer. Articles and runs are also stored only in your browser. Use Export data for backups.
